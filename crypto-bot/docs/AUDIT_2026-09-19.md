# Adversarial audit - 2026-09-19

Ten independent reviewers, one per subsystem, each told to report only
defects with a concrete failure scenario and to run a reproduction where
one was checkable. They returned 64 findings (56 after de-duplication).
Verification was done here by regression test: a finding counts as
**FIXED** only when a test that failed on the old code now passes
(`tests/test_audit_regressions.py`, 78 tests, plus changes to existing
suites), **REFUTED** when a measurement showed the claim false, and
**ACCEPTED** when it is real but left as a documented limitation.

The headline: the dry-run integration had defects that would have surfaced
within the first trade or the first three trades of the observation period,
and the research numbers were an artefact of one of them. None of this was
visible in a green test suite, because the suite tested the layers and not
the seams between them.

## Findings and what was done

Status: FIXED (with the regression test), REFUTED, ACCEPTED.

### Risk layer and state

| # | Finding | Status |
|---|---|---|
| R1 | Writer lock owner was the class name, identical for every process; a second instance "renewed" the lease instead of being refused, and the lease was never heartbeated. | FIXED - owner is `class:runmode:host:pid`; lease renewed every loop; losing it → `RECOVERY_REQUIRED`. `test_audit_writer_lock_*`, `test_audit_losing_the_writer_lock_*` |
| R2 | A crashed process on the same host held the lease for 300s; a systemd restart 30s after a crash was refused, five refusals hit `StartLimitBurst`. | FIXED - a dead pid on this host is taken over at once. `test_audit_writer_lock_left_by_a_dead_pid_*` |
| R3 | A refused second instance wrote `STOPPED` into the shared store, halting the running primary. | FIXED - a refused instance touches nothing. `test_audit_strategy_owner_is_unique_per_process` |
| R4 | Period baselines and the equity peak were only sampled when a signal fired; the day baseline was the equity at the first *attempt*, and an open-position breach went unnoticed until the next signal. | FIXED - `gate.observe()` every loop (every candle in backtests). `test_audit_observe_opens_the_baseline_*`, `test_audit_an_open_loss_trips_the_daily_lock_*` |

## What the audit did not find, and what that means

The sizing formula, the money model, the period-loss arithmetic and the
single-writer store held up: every finding against them was about *what
fed them* or *when they were called*, not about what they computed. The
seams - strategy callbacks to risk store, backtest to live loop, unit files
to filesystem - are where all the high-severity findings were.

Three findings changed the research verdict's arithmetic (R6, R19, and the
mark-to-market drawdown in P11/`eligibility.py`). The verdict itself did
not change: `INSUFFICIENT_EVIDENCE`, failing every criterion on the
evidence that exists.

What remains open after this audit is listed in `docs/PROJECT_STATE.md`.
